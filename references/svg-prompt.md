# doodle SVG 生成 Prompt 模板

> 用途：让任何模型/会话稳定产出与本系统一致的**手绘涂鸦内联 SVG**。两个用法：
> 1. **Agent 写码**：把「模板 B」整段塞进自己的生成前上下文（或作为 skill 指令），按主题填充后直接产 SVG 代码。
> 2. **生图模型**：把「模板 A」填好主题后喂给 ImageGen 类工具，产出位图插画位（空态大图、登录页 hero）。位图不能改色，优先用模板 B 出矢量化内联 SVG。

---

## 模板 A · 生图模型用（ImageGen）

```
手绘涂鸦贴纸风格插画：{主题描述，如"一台显示器里排着信号卡片和仪表盘"}。
纯白背景。所有物体用粗黑色墨线描边（均匀线宽，圆头线帽），像马克笔手绘。
填色只有三种：白色、奶油黄 #f9f0d8、荧光黄 #ffe28a（最多两处，用在最重要的焦点上）。
物体可以微微倾斜（±15° 以内）营造贴纸感。加 1-2 颗黄色四角星闪光作点缀。
禁止：渐变、真实阴影、透视、照片质感、文字、水印、多余颜色。
构图：单幅横版，主体居中偏左，留白呼吸感。
```

## 模板 B · Agent 直接写内联 SVG 用

把下面整段作为生成约束，`{}` 内按场景填充：

```
产出一个内联 <svg>，viewBox="0 0 320 168"（横版插画位）或按容器比例。
风格 = 手绘贴纸涂鸦（doodle sticker），不是图标库风格。硬规则：

【线条】
- 描边一律 stroke="#1a1a1a"，不许用别的颜色描边。
- 线宽分级：主轮廓 2.5-3.5；内部结构 1.8-2.2；细节线 1.5。同一层级线宽一致。
- stroke-linecap="round"、stroke-linejoin="round"，全部路径闭合或明显收笔。
- 直线允许轻微不平行（手绘感），但不用 path 抖动滤镜，靠 rotate 微倾斜实现。

【填色】
- 只允许：#ffffff 白、#f9f0d8 奶油底、#e3e1da 灰米色（次要占位条）、#ffe28a 荧光黄。
- 荧光黄 ≤ 2 处，只落在视觉焦点（选中块/关键仪表/星）。
- 禁止渐变、禁止 filter/drop-shadow。立体感用「实心 offset 硬投影」：
  在主体下方画一个偏移 2-3px 的同形深色块，或交给外层 CSS box-shadow。

【贴纸感】
- 主要物体用 <g transform="rotate(±3~15 ...)"> 微倾斜。
- 大件圆角 rx 6-10，小件 rx 2.5-4。

【点缀】
- 四角星标准 path（直接拷，transform translate 定位，可 scale）：
  <path d="M0 -9 Q1.6 -1.6 9 0 Q1.6 1.6 0 9 Q-1.6 1.6 -9 0 Q-1.6 -1.6 0 -9 Z"
   fill="#ffe28a" stroke="#1a1a1a" stroke-width="2" stroke-linejoin="round"/>
- 每幅 ≤ 2 颗星，位置错开（如右上 + 左下）。

【禁止】
- <text>（文字由 HTML 层出）；emoji；渐变；透视；照片质感；超出 viewBox 溢出裁切主体。

【场景】{一句话场景描述，如"工作台显示器 + 左侧菜单 + 中间信号卡 + 便签笔"}
```

## 快速验收清单（生成后过一遍）

- [ ] 所有 stroke 都是 `#1a1a1a`（grep 检查 `stroke="#` 无杂色）
- [ ] 荧光黄出现 ≤ 2 处且在焦点上
- [ ] 无 `linearGradient` / `filter` / `<text>`
- [ ] 线宽有层级（主轮廓明显粗于细节）
- [ ] 有至少一处微倾斜或弧线，没有纯水平垂直的"模板感"
- [ ] viewBox 内构图完整，主体不贴边
