## 自检问法（验收时逐条问）

1. 一级容器是否都有 2px 墨线 + 实心硬投影？投影是不是「糊」的模糊阴影（违规）？
2. 荧光黄出现几处？是否全部落在选中态/待办/人工闸门三种语义上？装饰性黄块 = 违规。
3. 四角星几颗？>2 = 违规。
4. 卡内数据区（表格/列表/日志）是否保持素净？卡内再套墨线 = 违规。
5. 按钮有没有三态（hover 翘起 / active 按下）？主按钮是否蓝底白字 + 墨线描边？
